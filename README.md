Reliable Command-Line Utility
Menu-Driven Expense Tracker Using C++

Project Description
This project is a simple menu-driven expense tracker developed using C++. It allows users to record expenses, view all expenses, calculate category-wise totals, and calculate the overall spending.

Features
1. Add new expenses.
2. View all recorded expenses.
3. Calculate total expenses by category.
4. Calculate overall expenses.
5. Validate user input and handle invalid values.
6. Exit the application safely.

Technologies Used
- Programming Language: C++
- Concepts: Structures, Functions, Vectors, Loops, Conditional Statements and Input Validation.
- Compiler: GCC

How to Compile and Run

Step 1: Download the C++ source file from this repository.

Step 2: Open a terminal in the folder containing the source file.

Step 3: Compile the program using:

```bash
g++ "Reliable command line utility.cpp" -o expense_tracker
```

Step 4: Run the program:

```bash
./expense_tracker
```

For Windows, use:

```bash
expense_tracker.exe
```

Sample Execution
The program displays a menu with five options:
- Add Expense
- View All Expenses
- Category Total
- Overall Total
- Exit

### Input Validation
The program checks for invalid menu choices, non-numeric amounts, negative amounts, and empty categories.
